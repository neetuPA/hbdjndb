#  Todo Backend API (Node.js + Express + MongoDB)

##  Project Overview
This is the backend for the Todo application built using Node.js, Express, and MongoDB.  
It provides REST APIs to create, update, delete, fetch, and search tasks.

---

##  Prerequisites
Make sure you have installed:
- Node.js 
- npm
- MongoDB 

---

##  Installation

Clone the repository and install dependencies:
in terminal ---npm i
